The agent skill now says how to use `--abstain-below` and `[model].max_len`, and the plugin version moves so installed copies pick it up. No behaviour changes: the scorecard is identical to v0.11.1, and `decide --jsonl` rows keep their shape.

**Agent skill**

- `--abstain-below P` marks each answer `passed` or `abstained` and never decides; a `uniform` answer is `unevaluated`; `P` is a threshold, not a calibrated chance.
- `max_len` reads more of a long state at a cost in time, accuracy past 512 is unmeasured, and `prompt_token_budget` clips first.
- Installed plugins only refresh when the plugin version changes, which is why this needs a release.
