Fixes from two more audits of the tool's implicit state, plus a pass that removed duplicated code. No model change; the scorecard is identical to v0.10.2.

**Answers and the server**

- A batch that fails part way keeps the answers it already has: `/v1/route/batch` and `decide --jsonl` return the finished rows and mark the rest, and the HTTP 207 answer is documented.
- `/healthz` says when the server has no model behind it (`ready: false` and a `reason`), still with status 200.
- `asked_as` (a yes/no rewritten as a choice) reaches the HTTP answer.
- A long state with no token budget is marked `truncated`. A backend that rounds its probabilities is no longer read as having no model.
- A flat answer is never decided on, and a flat second-tier answer in `cascade` never replaces the first tier's answer. A calibration fit of the wrong type, or with values outside 0 to 1, is refused.
- The truncation limit is fixed when an engine is built, and backends load once under threads. A closed backend is an upstream error, not a crash.
- A POST to a remote server is not sent again when the server may already have processed it. A read timeout is the one exception, and `bench` opts in to it.
- A run keeps the source of its first answer, server or in-process. `bench` refuses `--out` after a run the server answered, because that scorecard would not measure this machine's model. A pinned in-process run does not probe the server again.
- Config is read once per process, and `verdict config` names the file each key came from.

**`update`, `init`, the pre-commit hook**

- `verdict update` restores the old install on a second Ctrl-C, and `serve` and `update` share one install spec.
- `verdict init` and other config writes go through one atomic write that keeps a symlink and the file mode.
- The pre-commit hook tests one snapshot of the index and checks the exit status of every step, so a failed step can no longer pass.

**The training pipeline**

- A relabel is not repeated, and a label run that stopped part way is flagged. Stages refuse stale inputs, take a lock, and write atomically with unique temporary names.
- A failed commit of the Modal volume no longer kills a training run. The optimizer-step count is rounded up, and `--resume` refuses a checkpoint made from other items.
- An unpriced model cannot dodge the cost cap.

**Under the hood**

- One definition of the store keys, the split names, the Gemini URL, the stderr warning, the JSONL reader, the flag builder and the SystemOne key rule. The cascade failure row, the fit check and the checkpoint-name precedence each live in one place. `fields_named` takes structured instructions.
- The test doubles live in `tests/fakes.py` and in shared fixtures instead of being copied between files.
