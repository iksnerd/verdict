A fix for one warning. Nothing else changes: the scorecard is identical to v0.11.0, and `decide --jsonl` rows keep their shape.

**Fixed**

- The "`max_len` has no effect while `prompt_token_budget` is N" warning on the command line compared `max_len` with a fixed 512 before the model was loaded. It now waits for the checkpoint and compares with that checkpoint's own limit, so the multilingual checkpoint (1024) no longer gets a wrong warning at `max_len` 768.

Install: `uv tool install --python 3.11 'verdict[mlx,laya] @ git+https://github.com/iksnerd/verdict.git@v0.11.1'`, or `verdict update`.
